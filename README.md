# fast_use_mod

Fabric 客戶端模組（Minecraft 26.1.2）：**手上拿著終界水晶或螢石時，移除物品使用之間的 CD**，
外加一個重生錨用的自動切圖騰。

其他狀況完全等同原版 —— 不改挖掘、不改攻擊。唯一會多送的封包是切換快捷欄格子時的
`ServerboundSetCarriedItemPacket`，跟你自己按數字鍵送的是同一個。

## 功能

**1. 移除使用 CD**：主手或副手拿著指定物品（預設終界水晶、螢石）時，把 `Minecraft.rightClickDelay` 壓到 0，
所以按住右鍵時是每 tick 使用一次，而不是原版的每 4 tick 一次。

> 原版的 4 tick CD 本來就只擋「按住」右鍵，狂點右鍵原版自己就沒有 CD，所以測試時請**按住**右鍵比較。

**2. 重生錨充能後自動切圖騰**：對著**已經有充能**的重生錨拿螢石按右鍵時：

- 快捷欄有不死圖騰 → **不充能**，直接把選中格切到圖騰那一格（並立刻通知伺服器）
- 快捷欄沒有圖騰 → 不切格，照原版充能

不管有沒有圖騰，只要準心對著已充能的重生錨且手上是螢石，**都不會套用上面的無 CD**，
所以不會發生按住右鍵瞬間充滿 4 格的狀況。

## 使用方式

在「選項 → 控制 → 按鍵設定 → 快速使用」裡設定一個開關鍵，按下即可開／關（畫面上會顯示目前狀態）。

## 設定檔

`config/fast_use_mod.json`：

| 欄位 | 預設 | 說明 |
| --- | --- | --- |
| `enabled` | `true` | 總開關，對應按鍵切換 |
| `restrictToItems` | `true` | 只在手上有 `items` 裡的物品時生效；設成 `false` 則任何物品都生效 |
| `items` | 終界水晶、螢石 | 觸發的物品 id 清單，可自行增減 |
| `useDelayTicks` | `0` | 生效時保留的 CD tick 數，`0` 就是完全沒有 CD |
| `anchorTotemSwap` | `true` | 重生錨已充能時，改成切到圖騰那一格（同時停用該情況的無 CD） |

## 編譯

需要 JDK 25：

```bash
./gradlew build
```

產物在 `build/libs/`。
