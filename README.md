# fast_use_mod

Fabric 客戶端模組（Minecraft 26.1.2）：**手上拿著終界水晶時，移除物品使用之間的 CD**，
外加兩個自動切快捷欄的輔助（重生錨切圖騰、水晶放不下切黑曜石）。

其他狀況完全等同原版。唯一會多送的封包是切換快捷欄格子時的
`ServerboundSetCarriedItemPacket`，跟你自己按數字鍵送的是同一個。

## 功能

**1. 移除使用 CD**：主手或副手拿著指定物品（預設只有終界水晶）時，把 `Minecraft.rightClickDelay` 壓到 0，
所以按住右鍵時是每 tick 使用一次，而不是原版的每 4 tick 一次。

> 原版的 4 tick CD 本來就只擋「按住」右鍵，狂點右鍵原版自己就沒有 CD，所以測試時請**按住**右鍵比較。

**1-2. 挖掘中也能使用**：原版 `startUseItem()` 開頭有 `if (gameMode.isDestroying()) return;`，
所以左鍵按著挖方塊時右鍵完全沒反應。拿著指定物品時這個擋板會被拿掉，左鍵按著也放得了水晶。

**2. 重生錨充能後自動切圖騰**：對著**已經有充能**的重生錨拿螢石按右鍵時：

- 快捷欄有不死圖騰 → **不充能**，直接把選中格切到圖騰那一格（並立刻通知伺服器）
- 快捷欄沒有圖騰 → 不切格，照原版充能

**準心對著已充能的重生錨、手上是螢石或圖騰時一律不吃 CD**，不受 `items` 清單限制，
有沒有圖騰都一樣。所以充能 → 切圖騰 → 引爆是連續三個 tick，中間不會卡 4 tick。

> 代價是沒圖騰時按住右鍵會一路把錨充到 4 格（每 tick 一格）。要充一格就好的話用點的。

**3. 水晶放不下時先放黑曜石**：主手拿終界水晶按右鍵，但準心的位置放不了水晶時：

- 快捷欄有黑曜石 → 這一下改成**放黑曜石**，放完立刻切回水晶那一格
- 快捷欄沒有黑曜石 → 照原版（放不下就是放不下）

「放得下」的判斷跟原版 `EndCrystalItem.useOn` 完全一致：目標是黑曜石或基岩、上面那格是空的、
且上面兩格的範圍內沒有任何實體。水晶不看你點哪一面，永遠生在那顆方塊的正上方。

> 這一下**不套用無 CD**，黑曜石維持原版 4 tick 一顆的速度，不會按住右鍵就糊一整片。
> 黑曜石一放好、水晶變得放得下，下一下就又是無 CD 的水晶。

## 使用方式

在「選項 → 控制 → 按鍵設定 → 快速使用」裡設定一個開關鍵，按下即可開／關（畫面上會顯示目前狀態）。

## 設定檔

`config/fast_use_mod.json`：

| 欄位 | 預設 | 說明 |
| --- | --- | --- |
| `enabled` | `true` | 總開關，對應按鍵切換 |
| `restrictToItems` | `true` | 只在手上有 `items` 裡的物品時生效；設成 `false` 則任何物品都生效 |
| `items` | 終界水晶 | 觸發的物品 id 清單，可自行增減 |
| `configVersion` | `2` | 設定檔版本，用來自動升級舊設定，不要手動改 |
| `useDelayTicks` | `0` | 生效時保留的 CD tick 數，`0` 就是完全沒有 CD |
| `placeWhileMining` | `true` | 左鍵按著挖掘時，右鍵一樣可以使用物品 |
| `anchorTotemSwap` | `true` | 重生錨已充能時，改成切到圖騰那一格（同時停用該情況的無 CD） |
| `crystalObsidianSwap` | `true` | 水晶放不下時，這一下改成放黑曜石，之後切回水晶 |

## 編譯

需要 JDK 25：

```bash
./gradlew build
```

產物在 `build/libs/`。
